    运行说明

    零依赖、可独立运行：本 Demo 为单个 HTML 文件（HTML + CSS + 原生 JS），无框架、无构建、无后端、无网络请求。

    启动方式（任选其一）：

    1）直接用浏览器打开 demo/index.html（双击即可，file:// 下可正常运行）；

    2）或在项目根目录执行 http-server -c-1，访问 http://localhost:8080/demo/。

    演示流程

    ① 页面加载即自动随机一组自选信号：左侧自选列表出现信号横幅与个股高亮 → AI 主动推送一条盘面解读（主动触达）；

    ② 在下方"演示者操作台"选择一种用户发言类型（01 直接情绪宣泄 / 02 讽刺阴阳 / 03 对平台不满 / 04 质疑公司 / 05 决策纠结 / 06 灾难化放大 / 07 自责求安慰 / 08 冷静询问），系统会结合当前信号的个股、涨跌幅、量能与公告实时生成该类话术，点击示例句即模拟用户发送；

    ③ 展开"自由输入"可模拟真实键盘输入（含"割肉 / 要不要追"等决策词会触发合规交还路径）；

    ④ 右侧"AI 思考过程"按运行链路（信号解析 → 强度定级 → 情绪识别 → 意图识别 → 路由 → 合规分流 → 事实组装 → 措辞校验）逐条流式呈现；

    ⑤ 中部对话区以打字机效果输出三段式安抚回复：共情 → 事实 → 决策交还；

    ⑥ 点击右上角"重新随机一组信号"可反复体验不同信号 × 不同发言类型的组合；类型切换后示例句自动按新信号重写。

    与设计文档的对应

    信号定级 S1/S2/S3、情绪分级 E0~E3、路由路径 A/B/C/D、决策交还四动作、避免指令类措辞等逻辑，均按《回应过程设计说明》实现；股票与公告内容均为随机示例，非真实个股与披露信息，请勿作为投资依据。
